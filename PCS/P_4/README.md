# Практическое занятие №4 — «Интерактивный туристический путеводитель»

Веб-приложение на **ASP.NET Core MVC** + **Entity Framework Core 8** + SQLite.

Полноценный **интерактивный** путеводитель по городам России: карта, планировщик маршрута, избранное, живой поиск и случайные идеи для поездки.

## Запуск

```powershell
cd .\PCS\P_4\TouristGuide
dotnet run
```

Откройте **http://localhost:5272** — браузер откроется автоматически (Development).

## Интерактивные возможности

| Функция | Описание |
|---------|----------|
| **Живой поиск** | Строка в шапке — подсказки городов и мест без перезагрузки (`/api/guide/search`) |
| **Интерактивная карта** | Leaflet + OpenStreetMap, метки городов и достопримечательностей (`/Guide/Map`) |
| **Планировщик маршрута** | Добавление мест в поездку, расчёт бюджета билетов (`/Guide/Planner`, localStorage) |
| **Избранное** | Кнопка «В избранное» на карточках, список в планировщике |
| **Случайное место** | На главной — генератор идеи для путешествия |
| **Вкладки на странице города** | Карта · История · Места |
| **Мини-карта города** | Все достопримечательности на карте внутри страницы города |

## Разделы

| URL | Страница |
|-----|----------|
| `/` | Главная — KPI, случайное место, быстрые действия |
| `/Cities` | Каталог городов (поиск, регион, сортировка) |
| `/Cities/Details/{id}` | Город с вкладками и картой |
| `/Attractions` | Каталог мест (фильтры, цена) |
| `/Attractions/Details/{id}` | Страница достопримечательности |
| `/Guide/Map` | Интерактивная карта России |
| `/Guide/Planner` | Планировщик маршрута и избранное |

## REST API (для интерактива)

## Требования задания

| Требование | Реализация |
|------------|------------|
| Список городов | `Cities/Index`, `_CityCard` |
| Поиск по названию | + регион, описание; живой поиск в шапке |
| Страница города | история, герб, фото, места, **карта** |
| Достопримечательности | каталог + страница Details |
| `City`, `Attraction` | + координаты для карты |
| EF Core + SQLite | `touristguide.db` |

## Начальные данные

5 городов, 11 достопримечательностей. Координаты подставляются при каждом запуске.

Пересоздать БД:

```powershell
Remove-Item .\touristguide.db -ErrorAction SilentlyContinue
dotnet run
```

## Сборка


## Сценарий проверки

1. Главная → **«Случайное место»** — появится карточка с предложением.
2. В шапке введите **«кремль»** — выпадут подсказки.
3. На карточке места → **+ В маршрут** и **В избранное** → откройте **Маршрут** — увидите список и бюджет.
4. **Карта** → метки по России, фильтр по городу.
5. Страница города → вкладка **Карта** с местами.
