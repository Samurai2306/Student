# Практическое занятие №4 — «Туристический путеводитель»

Веб-приложение на **ASP.NET Core MVC** с **Entity Framework Core 8** и SQLite.

Путеводитель по городам России: карточки городов, страницы с историей и гербами, каталог достопримечательностей с часами работы и стоимостью входа.

## Запуск

```powershell
cd .\PCS\P_4\TouristGuide
dotnet run
```

Откройте адрес из консоли (обычно `https://localhost:7xxx`). **Главная страница — дашборд** (`/`).

## Функциональность

| Требование из задания | Реализация |
|------------------------|------------|
| Список городов (название, регион, население, фото, описание) | `Cities/Index`, карточки `_CityCard` |
| Поиск по названию | поле поиска + фильтр по **региону** и **краткому описанию** |
| Страница города | `Cities/Details` — история, герб, фото, список достопримечательностей |
| Список достопримечательностей на странице города | карточки `_AttractionCard` |
| Страница достопримечательности | `Attractions/Details` — история, фото, часы работы, стоимость |
| Модели `City`, `Attraction` | `Models/` |
| EF Core + БД | SQLite `touristguide.db`, сиды в `DbInitializer` |
| Контроллеры | `HomeController`, `CitiesController`, `AttractionsController` |

## Разделы приложения

| URL | Страница | Возможности |
|-----|----------|-------------|
| `/` | **Главная (дашборд)** | KPI, топ-3 города по населению, популярные места, быстрые ссылки |
| `/Cities` | Каталог городов | поиск, фильтр по региону (чипы), сортировка по названию / населению |
| `/Cities/Details/{id}` | Страница города | история, герб, достопримечательности, ссылка в каталог мест |
| `/Attractions` | Каталог мест | поиск, фильтр по городу, бесплатно/платно, сортировка |
| `/Attractions/Details/{id}` | Страница места | описание, часы, цена, «Ещё в этом городе» |

## Доработки интерфейса

- **Дашборд** с KPI: города, места, регионы, бесплатные входы;
- **Каталог достопримечательностей** — отдельная страница с фильтрами (город, цена, поиск);
- фильтр городов по **федеральному округу** (кнопки-чипы);
- сортировка городов: название, население ↑/↓;
- сортировка мест: название, город, цена ↑/↓;
- на карточках мест — ссылка на город (если загружен из каталога);
- блок **«Ещё в {город}»** на странице достопримечательности;
- современный адаптивный дизайн (Bootstrap + собственные стили);
- счётчики результатов поиска и фильтрации;
- бейдж с числом достопримечательностей на карточке города;
- заглушка изображения при ошибке загрузки фото (`placeholder-city.svg`);
- хлебные крошки на всех внутренних страницах;
- корректное склонение русских числительных (`DisplayFormat.Pluralize`).

## Начальные данные

При первом запуске создаются **5 городов**:

| Город | Достопримечательности |
|-------|------------------------|
| Москва | 3 |
| Санкт-Петербург | 2 |
| Казань | 2 |
| Сочи | 2 |
| Новосибирск | 2 |

Если база была создана ранее (только 3 города), при следующем запуске автоматически добавятся **Сочи** и **Новосибирск**.

Чтобы полностью пересоздать базу:

```powershell
Remove-Item .\touristguide.db -ErrorAction SilentlyContinue
dotnet run
```

Изображения хранятся как **URL** (Unsplash / Wikimedia), не в БД — по требованию задания.

## Примеры URL

| URL | Результат |
|-----|-----------|
| `/` | дашборд |
| `/Cities?search=моск` | поиск городов |
| `/Cities?region=Приволжский%20федеральный%20округ` | фильтр по региону |
| `/Cities?sort=population-desc` | города по убыванию населения |
| `/Attractions?fee=free` | только бесплатные места |
| `/Attractions?cityId=1&sort=price-asc` | места в городе, сначала дешевле |
| `/Cities/Details/1` | страница Москвы |
| `/Attractions/Details/1` | страница достопримечательности |

## Типовой сценарий проверки

1. Откройте `/` — проверьте KPI и блок «Популярные места».
2. **Города** → фильтр по региону «Южный» → должен остаться Сочи.
3. **Места** → вкладка «Бесплатно» → Красная площадь, Кремль и др.
4. Откройте достопримечательность → блок «Ещё в {город}» и хлебные крошки.
5. **Поиск** `море` на главной быстрой ссылкой или в каталоге городов.
